# Appendix C: Qualitative Analysis Codebook & Text-Mining Configuration

## C.1 Exploratory Concept Mapping (Leximancer 5.0)

A single Leximancer project was assembled from all seven sessions'
transcripts, observer fieldnotes, system chat logs, and open-ended survey
responses, converted to plain text and organized in a hierarchical folder
structure for automatic folder- and file-based tagging.

- **Mode:** User Defined + Automatic (preserves latent concept discovery
  while anchoring analysis in the study's theoretical framework)
- **Seed concepts:** 50 researcher-defined seed concepts organized across
  domains aligned with the five research questions, supplemented by seeds
  drawn from the computing-education research literature and system-level
  properties (e.g., privacy, hallucination, scaffolding, citation)
- **Kill list:** protocol-noise terms suppressed to keep the concept map
  focused on substantive discourse (e.g., screen, share, recording, upload,
  zoom, and other session-mechanics or conversational filler terms); for
  interview transcripts, automatically tagged speaker turns from the
  Interviewer were placed in the kill list so the concept map reflects
  participant discourse rather than interviewer prompts

## C.2 Iterative Qualitative Coding (MAXQDA)

A MAXQDA project was created with seven document groups (one per
participant), each containing four document types: session transcript,
observer fieldnotes, system chat log, and open-ended survey responses.

Coding proceeded iteratively: an initial set of parent codes was derived
from the research questions and the Leximancer concept map's sensitizing
leads, with child sub-codes added as they emerged from the data (new codes
were permitted to be added during coding rather than fixed in advance).
Each code carries an operational definition, explicit inclusion/exclusion
criteria, and at least one exemplar anchor quote. Parent-code categories
include: trust calibration behaviors, accuracy/faithfulness breakdowns,
pedagogical fit judgments, privacy/data-comfort reasoning, and adoption
workarounds.

## C.3 Cross-Case Thematic Matrix

Following individual coding, a cross-case matrix was constructed to compare
all seven participants on identical prompts/questions, supporting the
cross-case synthesis reported in the paper's Findings section (e.g.,
workaround-strategy frequency, citation-as-prerequisite consensus).
